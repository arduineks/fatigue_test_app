# Технический долг

Список долгов с приоритетами. Связанные задачи — в [BACKLOG.md](BACKLOG.md), решения — в [DECISIONS.md](DECISIONS.md).

## Высокий приоритет

### TD-1. Serial I/O в GUI-потоке
`calibration_window.py`: опрос порта QTimer каждые 5 мс при кадрах ~3 мс; чтение/запись
без блокировок, риск потери кадров и фризов UI.
**План:** `SerialManager` в QThread, кадры через сигнал; логику парсинга не менять.

### TD-2. Нет CRC и ACK-таймаутов
Валидность бинарного кадра определяется только маркерами 0xAA/0xBB (формат в
`protocol.py`); битый кадр принимается как валидный. Подтверждения команд не ждутся:
график очищается в `send_start` до получения `START_OK_YYY`.
**План:** CRC в протоколе (требует изменения прошивки STM32), проверка диапазонов полей
на ПК (можно сейчас), ACK-таймауты с повтором.

### TD-3. Отрисовка до 300k точек Python-циклом
`graph_widget.py` → `draw_signal`: `paintEvent` блокируется на длинной истории.
**План:** децимация до ~2k видимых точек + `QPainterPath`; альтернатива — pyqtgraph (обсудить).

## Средний приоритет

### TD-4. Буферы на списках
`del list[:n]`, `del rx_buffer[0]` — O(n) сдвиги при переполнении/потере синхронизации.
**План:** `deque(maxlen=...)` / ring buffer.

### TD-5. God-объекты внутри модулей
После ADR-001 остались два больших класса: `ForceGraphWidget` (график + приём кадров +
анализ циклов) и `CalibrationWindow` (UI + serial + калибровка + ini).
**План:** выделить `cycle_analyzer.py`, `data_buffer.py`, `serial_manager.py`.

### TD-6. Нет тестов
Ни одного теста; проверка только компиляцией и запуском.
**План:** юнит-тесты протокола и анализа циклов, smoke-тест instantiate окон (offscreen).

## Низкий приоритет

### TD-7. Мёртвый код и дубли
`add_value` (старые вызовы), `create_line_style_combo` (не используется), дубли логгеров
(`log` / `calibration_log`), кнопки, нарисованные вручную QPainter'ом.

### TD-8. Магические числа
`cycle_tolerance=0.03`, `cycle_turn_confirm=2` и др. без обоснования и настроек;
жёстко заданные `SERIAL_BAUD`, sample_rate=330, max_points=300000.
**План:** конфигурация/settings UI.

### TD-9. Неатомарная запись calibration.ini
`config.write` напрямую в файл — при сбое во время записи файл повреждается.
**План:** временный файл + rename.

### TD-10. Каталог backup/ в репозитории
Шесть старых версий main.py — исторический мусор. **План:** удалить.
