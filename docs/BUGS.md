# Известные баги

Формат: ID, серьёзность, статус, описание, воспроизведение, обходной путь.
Найденные при работе баги добавляются сюда; исправленные переносятся в «Исправлено».

## Открытые

### BUG-5 — AttributeError: on_interactive_field_changed (серьёзность: высокая) — исправлено 2026-10-06
В прерванной сессии сигналы `editingFinished` четырёх полей были подключены к
`on_interactive_field_changed`, но сам метод не был добавлен — любая правка поля
с валидным значением валила AttributeError. Исправлено: метод добавлен, логика
интерактивного режима завершена (ADR-005).

### BUG-1 — Возможная потеря измерительных кадров при активности UI (серьёзность: средняя)
Опрос serial QTimer'ом каждые 5 мс при кадрах ~3 мс: при загрузке GUI-потока
(перерисовка графика, меню) кадры могут теряться или опаздывать. Пика скорости не видно,
но длинные записи могут «замирать» на время перерисовки 300k точек.
**Обходной путь:** уменьшать окно истории (X-scale) на длинных записях.
**Связь:** TD-1, TD-3.

### BUG-2 — Битый кадр принимается как валидный (серьёзность: средняя)
Нет CRC и проверки диапазонов: кадр, случайно совпавший маркерами 0xAA/0xBB,
даёт выброс силы/позиции на графике и может сбить анализ циклов.
**Обходной путь:** визуально отфильтровать выбросы; перезапуск измерения.
**Связь:** TD-2.

### BUG-3 — Очистка графика до подтверждения START (серьёзность: низкая)
`send_start` очищает график/буферы сразу при отправке `START_YYY`; если устройство
не ответит `START_OK_YYY`, данные сброшены, а измерение не началось.
**Связь:** TD-2.

## Исправлено

### BUG-4 — Блоки показателей («МИН/МАКС СИЛА», «СРЕДНЕЕ», «ДЕЛЬТА», «КОЛИЧЕСТВО ЦИКЛОВ») не обновлялись (исправлено 2026-10-06)
Карточки анализа цикла создавались со значениями «0.00 N» и никогда не обновлялись:
`update_measurement_info` (таймер 100 мс) обновлял только «ВРЕМЯ». Исправлено:
в `update_measurement_info` добавлено обновление всех блоков из данных —
МИН/МАКС/СРЕДНЕЕ/ДЕЛЬТА (из `force_graph.cycle_min_value` / `cycle_max_value`),
КОЛИЧЕСТВО ЦИКЛОВ (`force_graph.cycle_count`), а также СИЛА и ПОЛОЖЕНИЕ ТРАВЕРСЫ
из последних принятых кадров (`last_force_n`, `last_current_mm`).
Дополнительно: `last_current_mm` теперь инициализируется в `__init__` (раньше
появлялся только в `send_start` — обращение до старта измерения дало бы AttributeError).
